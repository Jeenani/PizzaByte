### ПОРЯДОК РИСОВКИ (рекомендуемый)

1. `machine_body` + `machine_top_panel` — задаёт всю стилистику
2. `background_scene` — окружение
3. `robot_idle` — персонаж
4. `oven_*` + `dispense_*` — зоны корпуса
5. 9-slice UI (кнопки, панели) — запуск всего UI
6. Иконки ингредиентов — однотипные, батчем
7. Остальное

### ЗАМЕТКИ ДЛЯ ILLUSTRATOR

- Рисуй в векторе на любом размере, экспортируй PNG в указанных px
- 9-slice элементы: углы должны быть ~12px от края, центральная область должна корректно растягиваться
- Прозрачные вырезы на корпусе = alpha 0 в этих зонах (чтобы через них просвечивала печь, экран, слот)
- Размеры можно скорректировать под твой дизайн — в коде мы подстроимся
